MIA press kit

MIA is an open prototype that reads telemetry from a car, runs a voice assistant at the edge on a Raspberry Pi and pairs with an Android app. The first prototype vehicle is a 2004 Audi A4 Cabriolet (8H).

Fact sheet

NameMIA (the project was previously called AI-SERVIS)
StagePrototype. Checked by automated tests in CI and in simulation. No bench, hardware or in-vehicle validation is recorded yet.
HardwareRaspberry Pi 4B, ESP32 microcontrollers, an Android phone
Vehicle accessRead-only by default. MIA listens to OBD-II and CAN and does not send commands to the car.
Price and availabilityNot for sale. No price list. Pilot users and partners are welcome.
LicenceMIT, source code on GitHub

Evidence state of every requirement

What works today

  • OBD-II telemetry. Engine speed, coolant temperature, battery voltage and ignition state, from an ELM327 digital twin and passive CAN capture on ESP32.
  • Read-only Audi diagnostics. A VAG/Audi diagnostics bridge that only reads. MIA does not write to the vehicle bus by default.
  • Number plate recognition. Plate recognition in the Android app, with a Czech motorway vignette check.
  • Voice commands. Voice command handling on the Pi and spoken feedback in the Android app.
  • Android companion app. BLE pairing, a live telemetry card, dashcam recording and a local rules engine.
  • Raspberry Pi gateway. REST and WebSocket API, ZeroMQ messaging and systemd services, with simulation fallbacks when hardware is absent.
