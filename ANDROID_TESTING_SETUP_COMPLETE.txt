================================================================================
  TROUBLESHOOTING
================================================================================

Device Not Found:
  adb devices
  (Accept debug prompt on device if shown)
  adb devices  # Try again

Build Fails:
  cd apps/android
  ./gradlew clean assembleDebug --stacktrace

App Crashes:
  adb logcat -d | grep -A5 "AndroidRuntime: FATAL"

Test Hangs:
  adb shell am force-stop cz.mia.app
  adb shell am start -n cz.mia.app/.MainActivity

Subagent Not Spawning:
  • Verify in OpenClaw context (check: command -v sessions_spawn)
  • Manual fallback: bash scripts/spawn-test-tasks.sh logcat <file>

See ANDROID_TESTING.md for comprehensive troubleshooting.
